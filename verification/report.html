Identifier-index mentions and blanket bibliography inclusion are excluded from chapter citation counts. A citation establishes use by the book; it does not establish independent replication of a source’s empirical claims.

Method and limits

Current browser tests use a local HTTP server and real DOM controls in Chrome/Chromium. They check local navigation, collection filters, deep links, source inspection, exports, responsive layouts and current relation switches. Browser records are accepted as current only when graph counts and the interactive-HTML hash match this release. These are local browser checks, not a GitHub deployment or native Safari/iPad tests.

The structural checker resolves local files and fragments; it does not fetch every external URL. The separate October source review inspected primary metadata and the accessible passages documented in its audit. Access qualifications and actual author/excerpt credits remain attached to each article. The four online additions are not retroactively presented as manuscript citations.

Reproducibility uses the frozen baseline, audited article metadata, final bilingual chapter metadata and supplied Python builders. It rebuilds graph data before static pages without a source refresh. Runtime test reports, release reports and package checksum manifests are excluded from the byte-comparison set, avoiding circular report hashes.
