The Code Nobody Reads

Addy Osmani · 2026-09-28

When human line-by-line reading no longer scales, independently justified checks and accountable approval must replace its assurance role.

Verification & reviewEngineering structure

Osmani revises his earlier advice to inspect every generated line: routine low-risk changes may receive automated first-pass review, while high-blast-radius changes retain deeper scrutiny. Developers must deliberately practice reasoning, debugging and code comprehension when agents perform most implementation work.
