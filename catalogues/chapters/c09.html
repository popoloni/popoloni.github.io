Chapter 9: System Understanding, Context and Persistent Memory

A guide to the published second edition, with literal citations separated from wider editorial reading suggestions.

Open this group in the atlasChapter catalogue entry

Chapter guide

Treats context and persistent memory as claims with provenance, ownership and expiry. It develops software-specific knowledge records and invalidation rules, then uses a handoff and an explicitly limited retrieval comparison to test what a successor can reconstruct.

Comprensione del sistema, context e memoria persistente

Sintesi in italiano

Tratta context e memoria persistente come affermazioni con provenienza, responsabilità e validità. Sviluppa registrazioni della conoscenza software e regole di invalidazione, usando un passaggio di consegne e un confronto di recupero esplicitamente limitato per verificare ciò che un successore può ricostruire.

Learning goals

  • distinguish retrieved context from trusted system knowledge
  • design versioned memory with explicit invalidation rules
  • test a handoff by asking a new maintainer to reconstruct an operational decision from stored evidence
Obiettivi in italiano

Obiettivi di apprendimento

  • distinguere il context recuperato dalle conoscenze affidabili sul sistema
  • progettare una memoria versionata con regole esplicite di invalidation
  • verificare un handoff chiedendo a un nuovo maintainer di ricostruire una decisione operativa a partire dalle evidenze conservate
