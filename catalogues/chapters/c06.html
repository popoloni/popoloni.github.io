Chapter 6: Securing Generated Code and Agent Runtimes

A guide to the published second edition, with literal citations separated from wider editorial reading suggestions.

Open this group in the atlasChapter catalogue entry

Chapter guide

Threat-models two distinct surfaces: the generated application and the agent runtime. Dependency provenance, prompt injection, tool permissions and external services become enforceable boundaries, with security evidence tied to the release decision.

Mettere in sicurezza il codice generato e i runtime degli agent

Sintesi in italiano

Analizza due superfici di attacco distinte: l'applicazione generata e il runtime dell'agent. Provenienza delle dipendenze, prompt injection, permessi degli strumenti e servizi esterni diventano vincoli applicabili, collegando le evidenze di sicurezza alla decisione di rilascio.

Learning goals

  • threat-model the generated product and the agent runtime separately
  • enforce tool permissions independently of instructions embedded in files
  • specify the evidence required before accepting a security-sensitive patch
Obiettivi in italiano

Obiettivi di apprendimento

  • costruire threat model distinti per il prodotto generato e per il runtime dell'agent
  • far rispettare i permessi dei tool indipendentemente dalle istruzioni incorporate nei file
  • specificare le evidenze necessarie prima di accettare una patch sensibile dal punto di vista della sicurezza
