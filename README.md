# Knowledge Atlas for AI and Software Engineering

An independent, source-traceable map of research and practitioner writing about AI-assisted software development, by **Enrico Papalini**. The interactive graph and static catalogues connect publications, topics, engineering practices and book chapters while keeping evidence limits visible.

**[Open the published atlas](https://popoloni.github.io/swe_knowledge_graph.html)** · **[Local atlas](swe_knowledge_graph.html)** · **[Browse all catalogues](catalogues/index.html)** · **[Project homepage](index.html)** · **[Data downloads](downloads.html)**

Existing public atlas address: **[https://popoloni.github.io/swe_knowledge_graph.html](https://popoloni.github.io/swe_knowledge_graph.html)**. The relative links above work at the site root or within a GitHub project path.

## Start with the original collection

The foundation is **[The SE & AI Annotated Bibliography](https://www.sepolimi.com/p/se-ai-annotated-bibliography)**, curated by **Alfonso Fuggetta, Damian Andrew Tamburri and Alessandro Margara**, **Software Engineering @ PoliMi**. Its 8 October 2026 snapshot contains **193 works across nine thematic streams**. The source collection, original classification and annotations are the curators’ work. The graph, interface, independent summaries and editorial extensions are separate authorial work, not an official Polimi publication or endorsed interpretation.

The atlas opens with **W001–W193 only: 193 sources, 0 context nodes, 64 visible relationships**. The other collections are available but initially disabled. Existing clustering and all 297 relationship switches are preserved.

## About Enrico Papalini

Enrico Papalini is a software engineering leader and author based in Milan, Italy. With more than 25 years in software engineering and 15 in people management, his work focuses on AI-assisted development, intelligent automation and dependable financial-market systems. His career includes leadership roles at Euronext Securities, London Stock Exchange Group and Borsa Italiana. He writes the Non-Deterministic series and created this independent knowledge atlas.

## Publish on GitHub Pages

Copy **the contents of this package** into your configured Pages publishing folder, keeping the directory structure and `.nojekyll`. The entry page is `index.html`; the atlas keeps `swe_knowledge_graph.html`. No Jekyll, framework, API key, CDN or server application is required. See [DEPLOYMENT.md](DEPLOYMENT.md) before replacing an existing homepage. A ready-made `knowledge-atlas.html` entrypoint is also included.
